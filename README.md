One comedy one-liner, up to 280 characters, on any subject: a smart speaker asked for something relaxing answers with the one sound nobody finds relaxing.

> I asked my smart speaker to play something relaxing. It played my bank balance.

## How it works

`main.py` (Python 3 standard library only) writes the one-liner to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 280 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
